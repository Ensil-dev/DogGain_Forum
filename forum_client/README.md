# 🐶 DogGain_Forum

> **“개이득 정보를 나누는 유저 중심 커뮤니티 포럼”**  
> 실시간 핫딜 정보와 소비자 후기, 꿀팁을 공유할 수 있는 커뮤니티를 목표로 직접 기획하고 개발한 웹 포럼 서비스입니다. 유저 간의 정보 공유를 극대화하기 위해 게시판 기능 외에도 유효성 검증, 인증, 상태관리 등 웹앱의 핵심 기능을 갖추었습니다.

---

## 🔧 프로젝트 개요

DogGain_Forum은 "개이득(Hot Deal)" 정보를 중심으로 유저들이 자유롭게 소통할 수 있는 온라인 포럼 서비스입니다. 핫딜을 공유하거나 후기, 주의사항, 대체 상품 등 유용한 정보를 나눌 수 있으며, 기능적 완성도와 UX를 고려한 구조를 바탕으로 구성되어 있습니다.

핵심 기능 외에도 Firebase를 활용한 로그인, 클라우드 기반 데이터베이스 연동, 사용자 상태 유지 등 실전 개발 요소를 총망라하여 구현했습니다.

---

## 🎯 주요 기능 및 설계 의도

### 🗂 게시판 기능 (핫딜 정보 CRUD)

- **게시글 조회/작성/수정/삭제** 기능으로 정보 공유를 손쉽게 할 수 있도록 구성했습니다.
- **유효성 검사**를 통해 제목 10자 미만 입력 제한, 입력 필드 누락 시 버튼 비활성화 등의 UX 강화를 적용했습니다.

### 🔐 Google 로그인 및 사용자 식별

- **Firebase Authentication**을 활용하여 손쉬운 Google 로그인 기능을 제공하며, 사용자 구분을 통한 수정/삭제 권한 제어를 구현했습니다.

### ⚙️ 전역 상태 관리

- Redux Toolkit을 도입하여 로그인 정보, 게시물 상태 등을 일관되게 관리하고, `redux-persist`로 로그인 상태를 유지시켰습니다.

### 🔁 동적 라우팅

- 게시글 상세 페이지를 위한 **동적 라우팅** 처리로 URL 직접 접근과 공유 가능성을 확보했습니다.

### 🧠 Custom Hooks

- 입력 폼 유효성 검증, 컴포넌트 외부 클릭 감지 등을 위한 커스텀 훅을 설계해 **재사용성**을 높였습니다.

### 🎨 UI/UX

- **Styled-components**를 사용해 모듈화된 스타일링과 반응형 UI를 구성하고, 향후 **공통 버튼 컴포넌트** 설계를 통한 일관된 디자인 적용도 계획 중입니다.
